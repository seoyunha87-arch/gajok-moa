# 가족모아 — 가족 일정·사진 공유 앱

가족 구성원이 하나의 공간에서 일정을 함께 확인하고, 일부만 아는 일정은 비밀번호로 보호하고, 사진을 앨범으로 모아 보는 모바일 웹 앱입니다.

기능명세서(`가족 공간/구성원`, `가족 캘린더`, `비공개 일정 접근 관리`, `가족 앨범`)를 기반으로 만들었습니다.

## 사용해보기

첫 화면에서 회원가입 후, 가족 공간을 만들거나 초대 코드로 참여하면 됩니다. 서로 다른 기기에서 각자 가입해 같은 초대 코드로 참여하면 실제로 일정·사진이 공유됩니다.

## 백엔드

[Supabase](https://supabase.com)를 사용합니다 (인증, Postgres DB, Storage). 스키마와 Row Level Security 정책은 [`supabase/schema.sql`](supabase/schema.sql)에 있습니다.

- 비밀번호는 Supabase Auth가 해싱해 관리하며, 앱은 원문 비밀번호를 다루지 않습니다.
- Row Level Security로 가족 공간 간 데이터가 서로 격리됩니다.
- 비공개(비밀번호 보호) 일정은 `list_events`/`unlock_event` 함수를 통해서만 조회되어, 비밀번호 컬럼이 클라이언트로 전달되지 않습니다.
- 사진은 가족별 폴더로 분리된 비공개 Storage 버킷에 저장되고, 조회 시 서명된 URL(1시간 만료)로만 접근합니다.

## 로컬에서 열기

`index.html`을 정적 파일 서버로 열면 바로 실행됩니다 (Service Worker 등록을 위해 `file://`가 아닌 `http(s)://`로 열어야 합니다). 휴대폰에서 열면 전체 화면 앱처럼 보이고, "홈 화면에 추가"로 설치할 수 있습니다.

## 기술

순수 HTML/CSS/JS 단일 파일(+ Supabase JS SDK)로 작성했고, 빌드 과정이 없습니다.
