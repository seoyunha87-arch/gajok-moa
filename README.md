# 가족모아 — 가족 일정·사진 공유 앱

가족 구성원이 하나의 공간에서 일정을 함께 확인하고, 일부만 아는 일정은 비밀번호로 보호하고, 사진을 앨범으로 모아 보는 모바일 웹 앱 프로토타입입니다.

기능명세서(`가족 공간/구성원`, `가족 캘린더`, `비공개 일정 접근 관리`, `가족 앨범`)를 기반으로 만들었고, 모든 데이터는 브라우저의 localStorage에만 저장됩니다(별도 서버 없음).

## 사용해보기

데모 계정: `demo@family.app` / `demo1234` (또는 첫 화면에서 "데모 계정으로 둘러보기" 선택)

## 로컬에서 열기

`index.html`을 브라우저로 열면 바로 실행됩니다. 휴대폰에서 열면 전체 화면 앱처럼 보이고, "홈 화면에 추가"로 설치할 수 있습니다.

## 기술

순수 HTML/CSS/JS 단일 파일로 작성했고, 빌드 과정이 없습니다.
